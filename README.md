# Worker Pay Tracker

Create a simple Excel-style Construction Worker Salary Management website named "SATHISH CONTRACT MANAGEMENT SYSTEM".

IMPORTANT:

- No sign-in or login required.

- Keep the design simple, clean, and easy to use.

- Store all data in the browser so it remains saved after refreshing the page.

- Allow me to add, edit, and delete worker details.

WORKER DETAILS:

1. Worker ID

2. Worker Name

3. Phone Number

4. Work Type

5. Total Salary / Agreed Amount

6. Number of Days Worked This Month

7. Amount Settled / Paid

8. Balance Amount

9. Payment Status (Paid / Partially Paid / Unpaid)

10. Notes

FUNCTIONALITIES:

- Display all worker details in an Excel-like table.

- Add New Worker, Edit, and Delete buttons.

- Automatically calculate Balance Amount = Total Salary - Amount Settled.

- Display total workers, total salary, total amount paid, and total balance at the top.

- Search workers by name or phone number.

- Filter workers by Paid, Partially Paid, and Unpaid status.

- Allow me to record multiple payments for each worker.

- Include a month selector to manage monthly work and salary details.

- Allow me to export and download worker details as an Excel-compatible CSV file.

- Allow me to import worker details from a CSV file.

- Show a confirmation before deleting a worker.

- Make the website responsive for mobile and desktop.

- Use a simple white background, green highlights, and a professional table layout.

Use Indian Rupees (₹) for all amounts.

Use React, TypeScript, and Tailwind CSS if available.

No database, no backend, no authentication, and no unnecessary features.

Build a fully working website, not just a design or mockup.
